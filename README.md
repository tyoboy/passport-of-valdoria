An invented passport spread for the Republic of Valdoria, a coastal
republic whose capital is Sarenne. The data page carries a portrait,
bilingual Valdorian/English field labels and a machine-readable zone
for Elena Maris Voran, born in Sarenne; the visa page holds a Keralian
visitor visa (employment prohibited, fee paid) and entry/exit stamps
from Ostavia, Keralia and Nordmark that all postdate the passport's
issue in Sarenne on 03 MAY 2023. The image is rendered by a
deterministic program; `main.ts` writes it to `/output/entry.png`.

## Run it

```sh
node main.ts
```
